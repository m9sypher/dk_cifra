DK CIFRA

A Donkey Kong arcade hack by M9SYPHER

The four classic boards, four brand new ones, bonus rounds, an item shop, four difficulties and a new soundtrack, all running on the original arcade hardware through FBNeo.

Download How to patch

What’s new

Everything below is in the game the moment you patch it. No setup, no extra files.

Item shop

Spend coins between boards on a hammer, a bubble shield, double jump, speed shoes, extra lives and more.

Bonus rounds

Gamble Time, Present Drop and Barrel Hurdles: win coins and score after you clear a board.

Four difficulties

Normal, Hard, Expert and Insane, each with its own score multiplier. Only modes let you practice one board.

Records that save

Every difficulty keeps its own high score table, and the game saves the best ones by itself.

Level cards

See what’s coming before every board. Press Jump to skip ahead.

New music and sound

A new sound system with original and ported tunes for the title, the boards, name entry and game over.

Patch it and play

Four steps. Two of them are optional checks. Everything runs on your own computer, and nothing gets uploaded.

Download

Download DK CIFRA
One archive with two files:
  • dkcifra_v5.ips – the patch
  • dkong_m9.dat – tells FBNeo what’s in the patched zip

You also need: your own dkong.zip (Donkey Kong arcade, US Set 1), Lunar IPS (free, Windows), and RetroArch with the FBNeo core.

Check your dkong.zip optional

The patch was made from the merged dkong.zip below and has been tested on both a merged and a non-merged copy. It’s built to work with any version, merged, split or non-merged, so give yours a try even if the checksum doesn’t match. A different checksum just means your romset was zipped differently; it doesn’t stop the patch.

  • Exact match – the very zip the patch was made from.
  • Patch MAY work – a different version (merged, split or non-merged) that has all 15 original files enclosed: .
  • Patch MAY work – some of those files found; you can still try it.
  • No Donkey Kong files found – probably a different game.

How to patch with Lunar IPS

Lunar IPS was used to make the patch. It’s best to use it to apply it too, unless your patcher of choice can open and patch .zip files.

  1. Back up your dkong.zip. Lunar IPS changes the file you patch, so keep a copy of the original somewhere safe.
  2. Open Lunar IPS and press Apply IPS Patch.
  3. Choose the patch: dkcifra_v5.ips, then Open.
  4. Choose the zip: set the file type to All Files (*.*), pick your dkong.zip, then Open.
  5. Patched. “The file was successfully patched!”
  6. Rename it. Rename the patched dkong.zip to dkong_m9.zip (the .dat looks for that name). Put dkong_m9.zip and dkong_m9.dat in the same folder (or the .dat in RetroArch/system/fbneo/romdata/) and load dkong_m9.zip in the FBNeo core. Put your backup back as dkong.zip if you still want the original game.

Using RetroArch: load dkong_m9.zip with the FBNeo core. FBNeo finds the hack through dkong_m9.dat, so keep the .dat beside the zip (or in RetroArch/system/fbneo/romdata/).

Optional: extra record places (not needed)

The game saves by itself, with full names: NORMAL’s top 2, the #1 of HARD, EXPERT and INSANE, and each Only mode’s #1. No setup needed.

These lines only add the lower places (most difficulties’ places 2–5, and every Only mode’s full top 5). Paste them at the end of RetroArch/system/fbneo/hiscore.dat (RetroArch closed) and turn on Hiscores in the FBNeo core options. Back up hiscore.dat first.

Already have a dkongx line? If hiscore.dat already lists dkongx (often in a list like dkong,dkongj,...,dkongx:), that entry is for the original Donkey Kong II set, and FBNeo will probably use it instead of the dkongx block below. You could take dkongx out of that list, or add our 5 @: lines under it, but either way that changes how the real dkongx ROMs (if you have them as their own game) store their scores.

dkong_m9:
@:maincpu,program,7200,200,4d,39
@:maincpu,program,6f00,48,4d,39
@:maincpu,program,6230,50,4d,39
@:maincpu,program,61ca,36,4d,39
@:maincpu,program,608c,24,4d,39
dkongx:
